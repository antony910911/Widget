開始使用

照著下面的步驟做，每完成一步就會自動打勾。

    LINE 連線

    Webhook 網址 — 貼到 LINE Developers Console › Messaging API › Webhook URL

    ⚠️ 目前不是 HTTPS 網址，LINE 不接受。請用部署後的 https 網址開啟這個頁面。

    開啟 LINE Developers ↗

    分類規則

    依副檔名決定放進哪個資料夾。副檔名用逗號或空白分開。

    檔名關鍵字

    檔名包含任一個關鍵字，就自動加上標籤；有填子資料夾的話，會放進「分類/子資料夾」。

    備份

    下載全部檔案與資料庫（ZIP）。建議定期下載一份存到自己電腦。
