LINE 檔案櫃安裝

群組裡有人傳檔案，就自動存到你的 Google 雲端硬碟，依檔名分類、標記是誰傳的，還有網頁可以管理。照下面 4 步做，約 10 分鐘。

免費不用租主機只需要 Google 帳號可改存 OneDrive / Dropbox
完成 0 / 4 步
  1. 1

    開一個新的 Apps Script 專案

    點下面的按鈕，會在新分頁打開 Google Apps Script，並自動建立一個空白專案（需要登入 Google 帳號）。

    開新專案 ↗

    打開後可以點左上角「未命名的專案」改名為「LINE 檔案櫃」，方便以後找到。

  2. 2

    貼上程式碼

    按「複製程式碼」，回到 Apps Script，點編輯區、全部選取（Ctrl+A 或 ⌘+A）後貼上，取代原本的 function myFunction() {}。然後按 💾 儲存。

    複製按鈕沒反應？展開手動選取
  3. 3

    部署成網頁

    • 右上角 部署 → 新增部署作業
    • 「選取類型」旁的齒輪 → 網頁應用程式
    • 照下面設定，然後按 部署：
    執行身分
    我
    誰可以存取
    所有人

    「所有人」是為了讓 LINE 能把檔案送進來。管理介面另外有密碼，別人看不到你的檔案。

    • 按 授予存取權，選你的 Google 帳號
    • 出現「Google 尚未驗證這個應用程式」時，按左下 進階 → 前往「LINE 檔案櫃」（不安全） → 允許

    這個警告是因為程式是你自己的，不是上架的 App。它要求的權限是：存檔到你的雲端硬碟、建立一份清單試算表、連到 LINE。

    最後複製畫面上的網頁應用程式網址（https://script.google.com/macros/s/…/exec）。

  4. 4

    打開網址，完成設定

    用瀏覽器打開剛剛的網址，建立管理密碼，然後照著設定頁的「開始使用」清單做。每完成一項會自動打勾：

    • 在 LINE Developers 建立 Messaging API channel，把 Channel access token 貼進去
    • 把設定頁顯示的 Webhook 網址貼到 LINE 後台，開啟 Use webhook
    • 把 Bot 邀請進群組，傳一個檔案試試

    裝好請馬上打開網址建立密碼：在你設定密碼之前，任何拿到網址的人都能先設定。

    開啟 LINE Developers ↗

之後有新版本怎麼更新？

回到這頁複製新的程式碼，貼上覆蓋、儲存，然後「部署 → 管理部署作業 → ✏️ → 版本選新版本 → 部署」。用「管理部署作業」更新，網址才不會變。

檔案有大小限制嗎？

單一檔案最大約 50 MB（Google 的限制）。超過的會在設定頁的活動紀錄顯示並略過。

可以存到 iCloud 嗎？

不行，Apple 沒有開放 iCloud 雲碟給其他程式寫入。可以在 iPhone 裝 Google Drive 或 OneDrive App，它們會出現在「檔案」App 裡，跟 iCloud 一起看。

忘記管理密碼？

Apps Script 編輯器 → 左側齒輪「專案設定」→「指令碼屬性」→ 刪除 PW_HASH，再打開網址重新建立。
