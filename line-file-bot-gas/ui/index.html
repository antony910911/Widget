        開始使用

        照著下面的步驟做，每完成一步就會自動打勾。

          LINE 連線

          Webhook 網址 — 整串貼到 LINE Developers › Messaging API › Webhook URL

          網址最後的 ?key=… 是防止別人冒充 LINE 的密碼，請整串複製，不要外流。

          開啟 LINE Developers ↗

          儲存位置

          選擇新收到的檔案要存到哪裡。切換後，舊檔案會留在原本的位置，管理介面仍然看得到。

          分類規則

          依副檔名決定放進哪個資料夾。副檔名用逗號或空白分開。

          檔名關鍵字

          檔名包含任一個關鍵字，就自動加上標籤；有填子資料夾的話，會放進「分類/子資料夾」。
